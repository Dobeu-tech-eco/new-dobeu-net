- [L-016] Never read-modify-write a Vercel Sensitive env var: `vercel env pull` returns a placeholder for it, so writing it back destroys the real value. Set the full value from the owner via stdin (`vercel env add NAME env --force --sensitive`) and verify with the API's `updatedAt` metadata; `vercel env ls` shows the creation age, not the last update. (seen 1x, last 2026-11-04, source: run 20261103-213646)
- [L-017] Forbid sandboxed CLI builders (codex, muse) from running pnpm, npm, npx or any install; call node_modules/.bin/vitest, tsc and eslint directly. A sandboxed `pnpm` resolved to a different global version and wiped node_modules for the shared tree; restore only with the pinned pnpm and `--frozen-lockfile`, and check node_modules after every non-Claude dispatch. (seen 1x, last 2026-11-04, source: run 20261103-213646)
- [L-018] Make every guard or error message name a remedy that exists in the app (or a documented manual step); when none exists, add the missing action to the Ready queue. (seen 1x, last 2026-11-04, source: run 20261103-213646 final review)
- [L-019] When adding an audit row to a check-then-update state transition, make the update conditional on the status that was read (`.eq("status", current)` / `.in(...)`) and treat zero rows as a conflict, or the audited previous status can be false. (seen 1x, last 2026-11-04, source: run 20261103-213646 final review)
- [L-020] When a fix lands on one of two sibling code paths (createInvoice vs createInvoiceForWorkOrder), apply it to the sibling in the same change or record why not. (seen 1x, last 2026-11-04, source: run 20261103-213646 final review)
- [L-021] Treat an intermittent focus assertion as a possible component bug first: check whether the focus target is disabled or unmounted when the dialog closes before loosening the test; and assert a submit button's label or disabled state inside waitFor after an async submit, because under full-suite load the transition can still show its pending label. (seen 2x, last 2026-11-04, source: run 20261103-213646 fix round 2, ship pre-commit hook)

# Database types

`lib/database.types.ts` is generated by `pnpm db:types`. Keep schema explanations
in this document or the migrations and application aliases in separate modules.
`lib/work-order-types.ts` derives its aliases from the generated enums.

## Regeneration

Use the pinned Supabase CLI from the root package with Docker running. If no
local configuration exists, initialize it with `pnpm exec supabase init`, then
start the local database with `pnpm exec supabase db start` to apply the checked-in
migrations. Run `pnpm db:types`, format the output with
`pnpm exec prettier --write lib/database.types.ts`, and run `pnpm verify` from the
repository root.

The previous handwritten placeholder used empty `Relationships` arrays to
satisfy the Supabase client's table constraint. Generated output captures the
actual foreign keys, defaults, nullability, functions, and enums. PostgreSQL
text columns with `CHECK` constraints generate as `string`; callers must narrow
their values when a domain interface requires a specific set of statuses.
